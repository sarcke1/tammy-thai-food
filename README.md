# Tammy Thai Food — Phase 1

Prototype 100 % navigateur : HTML + CSS + JavaScript, sans installation.

Inclus :
- accueil responsive
- menu et panier
- simulation de commande
- file d’attente
- interface Tammy
- statuts En attente → En préparation → Prête
- estimation simple du temps de préparation

Aucun paiement réel et aucune donnée client envoyée à un serveur.

Prochaine étape : vraie base de données, créneaux de retrait, puis paiement.
